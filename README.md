# 文档转知识讲解视频（含右下角「视频通话」小窗）

把一份**文字稿（content.txt）**自动变成**竖屏/横屏的知识讲解视频**：每页 PPT 风格画面 + 逐句字幕 + TTS 配音 + 几何图动画，并在右下角叠加一个仿视频通话的小窗，用你上传的角色形象对口型。

本项目是 Trae 技能「视频生成」的可运行实现，`SKILL.md` 为该技能的完整说明（规格、配置字段、素材要求、自查清单）。

![演示](demo/通话小窗_演示.mp4)

## 特性

- **三步自动化**：内容解析 → 分页画面 + 配音字幕 → 合成导出 MP4
- **PPT 风格排版**：标题区、要点、口诀卡、几何示意图卡片，全部带动效（滑入 / 弹入 / 呼吸 / 脉冲）
- **逐句字幕**：按字数比例分配时间轴，与配音对齐
- **TTS 配音**：edge-tts 生成每页音频（可换音色）
- **右下角通话小窗**（可选）
  - 圆角卡片 + 白色描边 + 高斯投影，左上「通话中」绿点、底部姓名与计时、右下麦克风
  - 书房暖光背景（cover 裁切 + 虚化 + 暖色背光）
  - **音频驱动口型**：解析该页配音的音量包络（RMS，快起慢落平滑），逐帧驱动嘴巴开合 + 轻微呼吸缩放
  - 有几何图的页面自动改为「左图右文」，字幕宽度收窄，避免压住小窗

## 快速开始

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install moviepy pillow numpy edge-tts
```

1. 编辑 `content.txt`（全局设置 + 分页内容，格式见文件内示例或 `SKILL.md`）
2. 把自己的透明底角色图命名为 `avatar.png` 放进当前目录，小窗背景命名为 `avatar_bg.jpg`
3. 运行：

```bash
python3 generate_ppt_video.py
```

## 小窗配置（写在 `content.txt` 的全局设置区）

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| `形象` | `avatar.png` | 透明底角色图；留空或写 `off` 即关闭小窗 |
| `小窗背景` | `avatar_bg.jpg` | 小窗内背景图，缺省自动找 `avatar_bg.png/jpg/jpeg/webp` |
| `小窗尺寸` | `320` | 小窗宽度（像素），高度按 0.8125 比例 |
| `小窗位置` | `右下` | `右下` 或 `左下` |
| `小窗姓名` | `小墨` | 底部姓名标签，留空则不显示 |
| `口型` | `on` | `on` 音频驱动口型；`off` 只显示形象不动嘴 |
| `口型位置` | `0.50,0.427` | 嘴巴中心在形象包围盒的相对坐标（宽比例,高比例），换形象后微调 |

小窗的尺寸、边距、圆角、角标等视觉参数集中在 `avatar_talk.py` 顶部的 `DEFAULT_WINDOW`。

## 素材要求

- **形象图**：PNG，**透明底**，正面视角，嘴巴附近不要被手臂遮挡（口型是程序绘制的椭圆，靠坐标定位）
- **小窗背景**：横图更佳（4:3 或 16:9），画面尽量无人、无文字，因为有角色叠在上面

抠透明底的参考流程：多点 floodfill 去背景 → 颜色距离软 alpha → 收缩 1px → 低饱和亮带清除地面阴影 → 反混合去米色污染 → LANCZOS 上采样 + 锐化 → 再次清除底部残留。

## 文件结构

```
SKILL.md              技能的完整说明（规格 / 配置 / 流程 / 自查）
generate_ppt_video.py 主脚本：解析 content.txt → 逐页渲染 → 合成视频
ppt_style.py          版式与文字样式（标题、要点、口诀卡、几何图卡片、字幕）
svg_render.py         SVG → PNG 渲染（供 ppt_style 使用）
avatar_talk.py        右下角通话小窗：素材加载、窗口底图、音频包络、口型绘制、逐帧合成
avatar.png            示例角色形象（透明底）
avatar_bg.jpg         示例小窗背景（夜间书房暖光）
content.txt           示例内容配置
demo/                 演示视频
```

## 说明与限制

- 口型是**音量包络驱动**（不是音素级 lip-sync）：能跟着说话节奏张嘴、停顿闭嘴，重音处张得更开，但不会精确对应每个字的发音形状。
- 演示视频中的配音来自预置音频样本；正式使用需联网调用 edge-tts（部分网络环境可能 403，需要在能访问的环境下生成）。
- `content.txt` 中的几何图引用 `images/` 目录下的图片，仓库未附带示例几何图，可自行放置或先删掉 `几何图:` 这一行。

## 环境

macOS / Python 3.9+，依赖 MoviePy 2.x（验证版本 2.1.2）、Pillow、NumPy、edge-tts。
